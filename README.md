# SmartEats: Modern Eatery System

SmartEats is a full-stack restaurant management system built to streamline operations in modern eateries.  
It integrates backend services with simple dashboards to manage inventory, orders, and staff roles efficiently.

## Features
- Real-time inventory tracking
- Multi-role access (Admin, Cashier, Waiter)
- Secure REST APIs with Spring Boot
- Responsive dashboards using React/Next.js
- Containerized with Docker for easy deployment

## Tech Stack
- Backend: Java, Spring Boot
- Frontend: React.js, Next.js, Tailwind CSS
- Database: MariaDB / MySQL
- DevOps: Docker, GitHub Actions

## Project Structure
- `/RESTAURANT` → Initial backend setup
- `/backend2` → Core Spring Boot services
